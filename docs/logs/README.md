# Change logs

One file per major change to this repo, in chronological order
(`YYYY-MM-DD-NN-short-description.md`). Each entry records what changed,
why, and how it was verified, with the corresponding commit hash. This is
a durable record alongside git history — read it top to bottom for the
story of how the app got to its current state.
